Phosphor presentation layer

The Chamber is a PPI scope, not a spreadsheet. Contacts, sweep, and teleprinter cards make repo pressure feel like a room you can read at a glance.

Reusable scan engine

GitHub scanning lives in JavaScript modules, not inside workflow YAML. The same scoring logic powers local previews, stored JSON, markdown reports, and issue updates.

Static and dynamic paths

The dashboard reads generated JSON for GitHub Pages, and the local server can also expose a live API route when credentials are available.

Workflow-backed publishing

The scan workflow refreshes report data, uploads artifacts, and can keep the public-facing dashboard current without manual editing.

Resolved-failure suppression

Older failed workflow runs are filtered out when a newer success on the same workflow and branch has already resolved the problem, which keeps the feed focused on live friction.

Severity-aware controls

The dashboard can pivot by severity so you can isolate the hard blockers instead of treating every signal as visually equal.

Scan history

Each scan now records a compact trend snapshot, so the dashboard can show whether attention is rising, falling, or holding steady across recent runs.
